# 너몰이 프로젝트 제안서

> 너몰이 — 너만 몰랐던 이슈  
> 작성일: 2026-10-27 · 버전: 0.1

## 1. 서비스 한 문장

**여러 커뮤니티의 화제 이슈와 밈을 한곳에서 발견하고, 움직이는 한 컷·짧은 만화와 해설로 배경과 맥락을 이해하는 서비스.**

대상 : 분야를 가리지 않고 화제와 밈을 모두 알고싶은 한국 인터넷 유저.

## 2. 해결하려는 문제와 가설

| 사용자 문제 가설 | 제공하려는 가치 |
| --- | --- |
| 여러 커뮤니티를 방문해야 요즘 화제를 파악할 수 있다. | 여러 출처의 화제를 한곳에서 발견한다. |
| 같은 사건을 다룬 게시글을 반복해서 보게 된다. | 같은 이슈를 묶어 반복 탐색을 줄인다. |
| 제목만으로 사건의 배경이나 밈의 뜻을 이해하기 어렵다. | 짧은 만화·해설로 배경, 뜻, 사용 맥락을 설명한다. |
| 커뮤니티의 주장과 확인된 사실을 구분하기 어렵다. | 화제성, 확인된 사실, 미확인 내용을 구분하고 근거를 연결한다. |

## 3. 대표 이용 흐름

1. 홈의 전체 피드에서 현재 화제와 밈을 훑어본다.
2. 관심 있는 이슈를 열어 핵심 내용과 짧은 만화·해설을 읽는다.
3. 사건은 배경·쟁점, 밈은 뜻·유래·사용 맥락을 확인한다.
4. 관련 커뮤니티 글과 근거 원문으로 이동해 직접 확인한다.

움직이는 썸네일은 관심을 끄는 표현으로 사용한다.
